# Арена переговоров

**Попробовать онлайн:** https://arena-peregovorov-mvp.vercel.app

Тренажёр деловых переговоров. Вы садитесь за стол с персонажем, у которого есть публичная позиция и несколько интересов, о которых он молчит. Чтобы договориться выгодно, их нужно выяснить вопросами, а потом собрать пакет условий, который устроит обе стороны. После партии разбор показывает, где вы отдали лишнее. Любой ход можно вернуть, сказать иначе и сравнить две версии сделки.

Главное отличие от чат-тренажёров: результат считает код. Языковая модель играет человека напротив, с характером и манерой речи, но баллов не ставит и не решает, принято ли предложение. У каждого условия есть вес и фиксированные уровни, у обеих сторон свой запасной вариант. Выгодность пакета для второй стороны движок считает до того, как модель увидит ход, и передаёт ей готовое решение. Уговорить модель на лучший исход поэтому нельзя, его можно только выторговать.

## Как пройти за 10 минут

1. Откройте ссылку и нажмите «Начать». Первый кейс — привлечение инвестора на площадку особой экономической зоны.
2. Задавайте вопросы. Подходящий вопрос открывает скрытый интерес, а вместе с ним новое условие сделки.
3. Соберите пакет: что отдаёте и что просите взамен. Вторая сторона примет его, ответит встречным или откажет.
4. Посмотрите разбор, верните любой ход и сравните две версии.

Страница `/how` объясняет методики и систему оценки. Страница `/admin` нужна организатору: там можно описать ситуацию своими словами, настроить сложность, тон и цель второй стороны и получить ссылку для участников.

## Что внутри

- Семь кейсов: привлечение резидента, срыв сроков подрядчиком, невыполнение обязательств резидентом, рост тарифа поставщика, бюджет ИТ, сотрудник с оффером конкурента, скидка при продлении контракта.
- Три методики работают в механике: Гарвардский метод (интересы, пакеты, объективные критерии), SPIN (тип вопроса открывает интерес), BATNA (запасной вариант задаёт границу сделки).
- Балл из 100 складывается из семи показателей, от ценности сделки до сохранения отношений.
- Профиль переговорщика копит привычки, и со второй сессии вторая сторона становится жёстче там, где вы слабы.
- Если модель недоступна, ход доигрывает запасной движок на правилах, и партия не обрывается.

## Запуск локально

```bash
npm install
cp .env.example .env.local   # вписать ключ OpenRouter
npm run dev
```

Без ключа или с `DEMO_MODE=true` вторую сторону играет запасной движок, без обращений к сети.

Проверки работают офлайн:

```bash
npx tsc --noEmit
npx tsx scripts/audit-scenarios.ts
for f in scripts/check-*.ts; do npx tsx "$f" || break; done
```

## Устройство

```
lib/types.ts              модель мира: условия, уровни, интересы, факты
lib/engine/               полезность сторон, вердикт, скоринг, выбор моментов для разбора
lib/scenarios/            семь кейсов данными, без кода
lib/llm/                  промпт, разбор ответа модели, запасной движок
lib/admin/                настройка организатора, подбор кейса, ссылка для участников
app/api/turn/route.ts     ход: вердикт считается до обращения к модели
```

Next.js 15, React 19, TypeScript, Tailwind CSS 4. Модель подключается через OpenRouter.
