## 2. Ключ OpenRouter: что и куда вписывать

Ключ создаётся на **https://openrouter.ai/keys** (кнопка Create Key).

Открыть файл **`.env.local`** в корне проекта — он уже создан — и вписать ключ
в первую строку:

```
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ-сюда
OPENROUTER_MODEL=google/gemini-3.8-flash-20260902
DEMO_MODE=false
```

После правки `.env.local` **дев-сервер нужно перезапустить** — Next.js читает
переменные окружения только при старте.

Файл `.env.local` в git не попадает (он в `.gitignore`), ключ никуда не утекает.
На клиент ключ тоже не уходит: запросы к OpenRouter идут только с сервера,
из `app/api/turn/route.ts`.

### Какая модель используется и где её менять

Модель задаётся строкой `OPENROUTER_MODEL` в `.env.local`. Менять только там.

| Режим | Значение | Цена за миллион токенов | Когда |
|---|---|---|---|
| Разработка | `google/gemini-3.8-flash-20260902` | $0,75 / $3,75 | по умолчанию, для обычной игры |
| Демо и защита | `anthropic/claude-opus-5-20260723` | $5 / $25 | заметно живее в роли; полный прогон ≈ $0,20 |

Если `OPENROUTER_MODEL` не задан, код берёт flash-модель по умолчанию —
запасное значение лежит в `lib/llm/openrouter.ts`.

### Три режима работы

| `.env.local` | Что происходит |
|---|---|
| ключ есть, `DEMO_MODE=false` | живая модель играет оппонента |
| `DEMO_MODE=true` | сети нет вообще, играет детерминированный движок на правилах |
| ключа нет | то же, что `DEMO_MODE=true` — приложение не падает, а переключается само |

`DEMO_MODE=true` — режим для защиты: ничего не зависит от сети и провайдера.

## 3. Как тестить руками

### Что вводить

Оппонент раскрывает скрытый интерес только после подходящего вопроса.
Вот **проверенный прогон сценария «Привлечение резидента»** — доводит до
74 из 100 и открывает все четыре интереса:

1. `Что произойдёт с запуском, если мощность придёт позже марта?`
   → раскрывает срок техприсоединения
2. `С какими сложностями вы столкнулись с персоналом на прошлой площадке?`
   → раскрывает кадровый риск
3. `Расскажите, как вы сравниваете три площадки — какие сроки для вас критичны?`
   → раскрывает, зачем ему цена земли
4. `Правильно ли я понял, что решение по площадке утверждает совет директоров?`
   → раскрывает потребность в предсказуемости
5. Нажать **«Собрать предложение»**, выставить: подключение к марту,
   кадры 100 чел./год, объём 1,5 млрд, 340 рабочих мест, запуск II кв. 2027.
   В поле формулировки написать, например:
   `Гарантируем двенадцать мегаватт к марту и берём на себя подготовку кадров. Взамен фиксируем полтора миллиарда, триста сорок рабочих мест и запуск во втором квартале.`

По ходу отмечай гипотезы: они всплывают прямо в разговоре после сильного
вопроса, либо во вкладке **Досье** справа. Без них теряется 15 баллов.

### Какие формулировки работают

Движок распознаёт тип вопроса по корням слов. Рабочие заготовки:

| Тип | Начинай так |
|---|---|
| последствия | «что произойдёт, если…», «чем обернётся…», «к чему приведёт…» |
| проблемы | «с какими сложностями…», «что мешает…», «где узкое место…» |
| контекст | «расскажите, как…», «какой график…», «как обстоят дела с…» |
| ценность решения | «что бы вам дало…», «насколько важно…», «решило бы это…» |
| полномочия | «кто принимает решение…», «что согласует совет…» |
| активное слушание | «правильно ли я понял, что…», «то есть вы…» |
| объективный критерий | «по рынку…», «в среднем по отрасли…», «индекс показывает…» |

Это нужно только в режиме `DEMO_MODE=true`. С живой моделью говори как угодно —
она понимает свободную речь.

### Что стоит проверить отдельно

- **Провал.** Отвечать невпопад до конца раундов → должно быть
  «Раунды закончились, соглашения нет», а не «сделка состоялась».
- **Уступка даром.** Собрать предложение, отдав только подключение и ничего
  не попросив → в разборе появится развилка «Уступка без встречного условия».
- **Выход.** Кнопка «Выйти из переговоров» слева внизу — легитимный исход.
- **Развилка.** В разборе на шаге «Как можно было иначе» выбрать момент,
  сказать иначе → сравнение двух веток. Прогон помечается тренировочным.
- **Профиль.** После двух зачётных прогонов на `/profile` появятся паттерны.

## 6. Архитектура

```
lib/types.ts              модель мира
lib/engine/utility.ts     полезность сторон, BATNA, ZOPA, граница Парето
lib/engine/state.ts       редьюсер хода, вердикт по предложению, архетипы
lib/engine/scoring.ts     детерминированный подсчёт 100 баллов
lib/engine/rewind.ts      выбор моментов для переигрывания
lib/scenarios/            четыре сценария данными, без кода
lib/llm/                  промпт, строгая схема ответа, офлайн-оппонент
lib/profile.ts            профиль переговорщика в localStorage
app/api/turn/route.ts     ход: вердикт считается ДО модели и передаётся ей
```

Ключевое правило: **LLM играет персонажа и размечает речевые акты, но не
ставит баллы и не решает, принято ли предложение.** Экономику и исход считает
код. Модель получает вердикт как данность и только формулирует реплику.

Условия сделки дискретны: у каждого 3–4 уровня, а не диапазон. Это даёт
границу Парето полным перебором, стабильный ответ модели (она выбирает id
уровня, а не выдумывает числа) и читаемый терм-шит.

## 7. Если не запускается

**`Cannot find module '../lightningcss.darwin-arm64.node'`** — зависимости
ставились не с macOS, нативные бинарники встали под чужую платформу:

```bash
npm install --os=darwin --cpu=arm64 --include=optional
```

**Оппонент отвечает шаблонно** — работает офлайн-движок. Проверить, что в
`.env.local` есть ключ, `DEMO_MODE=false`, и что дев-сервер перезапущен.
